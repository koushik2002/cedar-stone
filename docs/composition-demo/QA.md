# Composition demo verification

Checked 20 October 2026 using headless Chrome with an isolated browser profile. These are desktop and mobile viewport emulations, not physical-device or Safari certification.

**80 browser checks passed, with zero failures.** [Recorded results](browser-checks.json).

The checks covered the section order and palette; loaded fonts and twelve samples; pointer/button plaster; reversible rough-edged wall coatings; pinned stage legend; texture/colour selection; exact finish transfer to the compact form; continuous material track, filters, last-board reachability, release to vertical content, keyboard focus and dialogs; tape extension, case movement, hook visibility, graduation/label structure, readable final place, reverse scrolling, range/keyboard control; process fills; required/whitespace/email validation, safe text rendering, actual text-file download, clipboard feedback and reset.

No horizontal page overflow was found at 1600×1000, 1440×900, 1280×800, 1024×768, 850×900, 768×1024, 390×844, 360×780, 320×740 or 844×390. Wall controls, final material and tape endpoint controls were checked at 390 and 320 pixels. Mobile navigation, focus, dialogs and selection were exercised. Reduced motion and short landscape views preserve exploration without pinned scenes; restoring motion resets the native tape offset.

No uncaught JavaScript exceptions or third-party runtime requests occurred. Static validation passed for 59 unique HTML IDs, anchors, local asset references, seventeen SVG XML files, three font signatures and the included font license.

After the main run, a cosmetic refinement smoothed plaster-stroke edges and widened their mobile composition. The plaster button/pointer and the opening layouts were rechecked before publication. The primary behavioural implementation is unchanged.
